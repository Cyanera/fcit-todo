# مهام FCIT

بوت يستمع لقروب واتساب بشكل مستمر، يستخرج المهام الموجّهة لك تحديدًا، ويعرضها في
لوحة عربية مع تنبيه فوري للعاجل منها.

يشتغل بوضعين: **قواعد** بصفر تكلفة، أو **تصنيف ذكي عبر Claude** أدق وأشمل.

الهدف: تتوقف عن متابعة القروب لحظة بلحظة، وتفتح اللوحة لما تكون فاضي.

---

## كيف يشتغل

```
قروب الواتساب
   │  Baileys — جهاز مرتبط، يستمع 24/7
   ▼
تجميع الرسائل في دفعات (كل 60 ثانية أو 25 رسالة)
   │  دفعة واحدة بدل استدعاء لكل رسالة = تكلفة أقل وسياق أوسع
   ▼
الاستخراج — يحدد لكل رسالة: هل هي مهمة عليك؟
   + العنوان + من طلبها + الموعد + الأولوية + نسبة الثقة
   (عبر Claude في الوضع الذكي، أو بقواعد عربية بصفر تكلفة)
   ▼
SQLite ──► لوحة ويب على المتصفح
        └► تنبيه فوري في "رسالة لنفسي" للمهام العاجلة
        └► ملخص يومي الصباح
```

كل مهمة تحتفظ بنص الرسالة الأصلية واسم مرسلها ووقت إرسالها، فتقدر ترجع
للسياق قبل ما تنفّذ.

> واتساب لا يوفّر رابطًا يفتح رسالة بعينها — روابطه تفتح محادثة مع شخص أو
> دعوة قروب فقط — فلا يمكن جعل الضغط على الرسالة ينقلك إليها داخل التطبيق.

## التشغيل

### 1. المتطلبات

- Node.js 20 أو أحدث
- رقم واتساب
- مفتاح Claude — **اختياري**، للوضع الذكي فقط.
  من [console.anthropic.com](https://console.anthropic.com/settings/keys) (يحتاج رصيد مدفوع،
  أقله ٥$). بدونه يشتغل البوت بوضع القواعد.

### وضعان للتشغيل

| | **قواعد** (`MODE=rules`) | **ذكي** (`MODE=claude`) |
|---|---|---|
| التكلفة | صفر | رصيد API مدفوع |
| يقرأ | كل رسائل القروب | كل رسائل القروب |
| يلتقط | أي رسالة فيها إشارة طلب — جماعية كانت أو باسمك | نفسه، مع فهم السياق |
| يستبعد | الموجّه لزميل بالاسم، والتحيات والشكر | نفسه، بدقة أعلى |
| العنوان | نص الرسالة بعد تنظيف النداء | معاد صياغته بصيغة أمر |
| يفوته | الطلب الضمني بلا صيغة طلب واضحة | قليل |

`MODE=auto` (الافتراضي) يختار الذكي لو وجد مفتاحًا صالحًا، وإلا القواعد. يعني تقدر
تبدأ اليوم بصفر تكلفة، وتضيف المفتاح لاحقًا فينتقل وحده بدون أي تغيير ثانٍ.

**المهام الجماعية هي الغالب** في قروبات العمل («لازم نرفع الدرجات قبل الخميس»)،
لذلك الوضعان يلتقطانها بلا اشتراط نداء باسمك. `MY_NAMES` يرفع الثقة فقط،
و`OTHER_NAMES` يستبعد ما هو موجّه لزملائك.

### الاختبارات

```bash
npm test
```

١١ اختبارًا تغطي: الالتقاط الجماعي، استبعاد ما هو لزميل، الضجيج، التباس الأسماء،
تمييز الماضي من الأمر، وتحويل المواعيد. **شغّلها بعد أي تعديل على قوائم الكلمات
في `src/rules.js`** — أضف حالتك الجديدة كاختبار أولًا.

**حد وضع القواعد:** لا يفهم الزمن ولا السياق. يستبعد صيغ الماضي («أرسلت التعميم»
خبر لا طلب)، لكن ستمرّ بعض الإيجابيات الكاذبة — احذفها بضغطة من اللوحة.

### 2. التثبيت

```bash
npm install
cp .env.example .env
```

افتح `.env` واضبط:

| المتغير | الشرح |
|---|---|
| `MODE` | `auto` / `rules` / `claude` — انظر الجدول فوق |
| `ANTHROPIC_API_KEY` | مفتاحك من الكونسول. اتركه كما هو لتشغيل وضع القواعد |
| `MY_NAMES` | الصيغ التي ينادونك بها — ترفع ثقة المهام الموجّهة لك |
| `OTHER_NAMES` | أسماء زملائك — أي طلب موجّه لهم يُستبعد من مهامك |
| `INCLUDE_OWN_MESSAGES` | `true` لالتقاط رسائلك أنت — مفيد للتجربة وحدك |
| `GROUP_JIDS` | معرّف القروب (تجيبه في الخطوة 4) |
| `CLAUDE_MODEL` | `claude-opus-5` افتراضيًا. للقروبات كثيرة الحركة جرّب `claude-sonnet-5` |
| `MIN_CONFIDENCE` | الحد الأدنى لتسجيل المهمة. ارفعه لو طلعت مهام زائدة |

> `npm start` يطبع لك عند الإقلاع أي وضع يشتغل فيه، واللوحة تعرضه في الأسفل.

### 3. ربط واتساب

```bash
npm run login
```

يطلع رمز QR في الطرفية. من جوالك: **واتساب ← الإعدادات ← الأجهزة المرتبطة ← ربط جهاز**.
الجلسة تُحفظ في `data/wa-auth` فما راح تحتاج تعيدها.

### 4. معرفة معرّف القروب

```bash
npm run groups
```

يطبع قروباتك مع معرّف كل واحد. انسخ سطر `GROUP_JIDS=` للقروب المطلوب وحطه في `.env`.

> لو تركت `GROUP_JIDS` فاضي راح يقرأ **كل** قروباتك — مكلف وغير دقيق. حدّد قروبك.

### 5. التشغيل

```bash
npm start
```

اللوحة على `http://localhost:3777`.

## التشغيل الدائم على الماك

عشان يبقى شغالًا بعد إغلاق الطرفية، استخدم `launchd`. أنشئ
`~/Library/LaunchAgents/com.local.whatsapp-tasks.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key><string>com.local.whatsapp-tasks</string>
  <key>ProgramArguments</key>
  <array>
    <string>/usr/local/bin/node</string>
    <string>/المسار/الكامل/whatsapp-tasks/src/index.js</string>
  </array>
  <key>WorkingDirectory</key><string>/المسار/الكامل/whatsapp-tasks</string>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
  <key>StandardOutPath</key><string>/tmp/whatsapp-tasks.log</string>
  <key>StandardErrorPath</key><string>/tmp/whatsapp-tasks.err</string>
</dict>
</plist>
```

ثم:

```bash
launchctl load ~/Library/LaunchAgents/com.local.whatsapp-tasks.plist
```

استبدل `/usr/local/bin/node` بمخرج `which node` عندك.

> **انتبه:** الماك لما ينام ينقطع الاتصال بواتساب وتفوتك رسائل تلك الفترة.
> لو تبغى تغطية كاملة، شغّل `caffeinate -s` أو انقل المشروع لسيرفر صغير.

## ملاحظات مهمة

**حارس الإرسال — لا يستطيع الكتابة في أي قروب.** `src/guard.js` يُركَّب على
دالة الإرسال في المقبس نفسه فور إنشائه، ويرمي استثناءً لأي وجهة عدا محادثتك مع
نفسك: القروبات والأشخاص والقنوات والقوائم كلها ممنوعة. لأنه على المقبس لا على
شيفرة الاستدعاء، فهو يغطي أي شيفرة تُضاف مستقبلًا، ولا يمكن استبداله بعد تركيبه
(`writable: false`). تغطيه ٨ اختبارات في `test/guard.test.mjs`.

للتحقق بنفسك من أن الإرسال لا يحدث إلا لنفسك:

```bash
grep -rn "sendMessage" src/
```

**الاتصال بالقروبات غير رسمي.** واجهة واتساب الرسمية (Cloud API) لا تدعم قراءة رسائل
القروبات إطلاقًا، لذلك يستخدم المشروع مكتبة `Baileys` التي تربط رقمك كجهاز مرتبط —
نفس آلية WhatsApp Web. هذا خارج شروط استخدام واتساب، والخطر الواقعي هو احتمال حظر
الرقم. البوت هنا **قارئ بشكل أساسي** ولا يرسل إلا لمحادثتك مع نفسك، وهذا يقلل
الخطر كثيرًا لكنه لا يلغيه. لا تستخدمه على رقم لا تتحمّل فقدانه.

**خصوصية أعضاء القروب.** رسائل القروب تُخزّن محليًا في `data/tasks.db`، ونصوص الدفعات
تُرسل لـ Claude للتصنيف. المجلد كامل مستثنى من Git. انتبه لهذا قبل ما تشغّله على
قروب فيه نقاشات حساسة.

**الدقة تحتاج ضبطًا.** أول يومين راح تطلع مهام زائدة أو ناقصة. عدّل:
- `MY_NAMES` — أضف كل صيغة ينادونك بها فعليًا (هذا أكبر مصدر للتحسين).
- `MIN_CONFIDENCE` — ارفعه لتقليل الضجيج، أنزله لو فاتته مهام.
- في الوضع الذكي: قسم "ما لا يُعتبر مهمة" في `src/classify.js`.
- في وضع القواعد: `RULE_KEYWORDS` في `.env`، أو قوائم الإشارات في `src/rules.js`.

المهام اللي ثقتها أقل من 75٪ تظهر في اللوحة بوسم "راجعها".

**الخطوط.** اللوحة تستخدم خط ثمانية (Thmanyah Sans) بخمسة أوزان. ملفات الخط **غير
مرفوعة** للمستودع لأن ترخيص إعادة التوزيع يخص ثمانية — انسخها محليًا إلى
`public/fonts/` بالأسماء `thmanyahsans-{Light,Regular,Medium,Bold,Black}.woff2`.
بدونها تشتغل اللوحة بخط النظام تلقائيًا دون أي خطأ.

**الثيم.** زر في أعلى اللوحة يبدّل بين: تلقائي (حسب النظام) ← فاتح ← داكن،
والاختيار محفوظ في المتصفح.

**المهام اليدوية.** زر «+» الدائري يضيف مهمة لم تأتِ من القروب — تظهر بوسم
«✎ يدوية» وتُعامل مثل بقية المهام. الإضافة اليدوية تتخطى فحص التكرار، لأن التكرار
فيها قرارك أنت. اختصار: `Cmd/Ctrl+Enter` للإرسال، و`Esc` للإغلاق.

## التكلفة

**وضع القواعد: صفر.** ما يتصل بأي خدمة مدفوعة إطلاقًا.

أما الوضع الذكي: الدفعة الواحدة (25 رسالة تقريبًا) تستهلك ~1500 توكن دخل و~200 خرج.
التعليمات الثابتة مخزّنة في الكاش فتُحسب بربع السعر بعد أول استدعاء.

قروب متوسط الحركة (300 رسالة يوميًا) ≈ 12 دفعة، وهو استهلاك يومي بسيط.
لو القروب كثير الحركة، `CLAUDE_MODEL=claude-sonnet-5` يقلل التكلفة للنصف تقريبًا.

## البنية

| الملف | الدور |
|---|---|
| `src/wa.js` | اتصال واتساب، استخراج نص الرسائل، إعادة الاتصال |
| `src/pipeline.js` | تجميع الدفعات، حفظ المهام، التنبيهات والملخص |
| `src/classify.js` | تعليمات Claude ومخطط الإخراج المنظّم (الوضع الذكي) |
| `src/rules.js` | استخراج بالقواعد والمواعيد العربية (وضع القواعد) |
| `src/db.js` | SQLite ومنع تكرار المهام |
| `src/server.js` | واجهة REST للوحة |
| `public/` | اللوحة |
| `src/guard.js` | حارس يمنع الإرسال لأي قروب أو شخص |
| `test/` | اختبارات القواعد والحارس |
